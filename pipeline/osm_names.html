Name places from OpenStreetMap

Open inbox/places_todo.json (written by build.py), press Run. Your browser asks overpass-api.de for the nearest named thing within 60 m of each place (about 3,000 places → ~75 small requests, a few minutes; the log shows progress per batch). When done, save the download as inbox/osm_places.json and run build.py again. Manual names in labels.json always win.

Privacy note: this sends the coordinates of your frequent places to the Overpass server, in batches of 40. Nothing else leaves your browser. Don't run it if that is not OK for you.
